Fipc on NuGet · using FastIpc

C#

Two layers. FipcListener and FipcConnection are objects on SafeHandles that are safe to dispose from any thread. Underneath, Fipc declares the C API one to one over IntPtr handles, for the hottest loops. The package targets .NET Standard 2.1 and carries the native libraries for Linux x64 (glibc 2.34+), Windows x64 and macOS 14.4+ on Apple Silicon (osx-arm64).

Server and client

two processes, one name

A server listens on a name and accepts one client at a time; a client connects to the name, and Connect waits for the server to listen and accept, so the two run in different processes or on different threads. Each program is a console project of its own (dotnet new console) with the Fipc package. Timeouts are int milliseconds, the last parameter: 0 doesn't wait, Fipc.Forever (−1, like Timeout.Infinite) waits for ever. The pair makes the exchange every example on this site makes, an RPC request with opcode 1 and the payload ping, answered in upper case: this client works with any language's server, and this server with any language's client (every pair of languages is tested).

Server/Program.cs
using System.Text;
using FastIpc;

// rings of 1 MiB each way
FipcListener.Listen("my_channel", 1 << 20,
    out FipcListener? listener);
using (listener)
{
    // waits for a client
    listener!.Accept(out FipcConnection? conn, Fipc.Forever);
    using (conn)
    {
        if (conn!.RpcReceive(out FipcRpcHeader request,
                out byte[] payload, Fipc.Forever)
            == FipcResult.Ok)
        {
            string upper = Encoding.UTF8.GetString(payload)
                .ToUpperInvariant();
            conn.RpcRespond(request.Id, request.Opcode, 0,
                Encoding.UTF8.GetBytes(upper), Fipc.Forever);
        }
    }
}
Client/Program.cs
using System.Text;
using FastIpc;

if (FipcConnection.Connect("my_channel",
        out FipcConnection? conn, 5000) != FipcResult.Ok)
    return 1;
using (conn)
{
    conn!.RpcSubmit(opcode: 1, "ping"u8, out ulong id,
        Fipc.Forever);
    conn.RpcReceive(out FipcRpcHeader response,
        out byte[] reply, Fipc.Forever);
    Console.WriteLine(Encoding.UTF8.GetString(reply));  // PING
}
return 0;

Plain messages

bytes of any size, no header

Without RPC, a connection carries plain messages: Send takes a message of any size, and Receive returns each one whole in a new array (or fills your span). This server echoes every message back until its client leaves, which ends its next Receive with Disconnected.

EchoServer/Program.cs
using FastIpc;

// rings of 1 MiB each way
FipcListener.Listen("demo", 1 << 20, out var listener);
using (listener)
{
    listener!.Accept(out FipcConnection? conn, Fipc.Forever);
    using (conn)
    {
        while (conn!.Receive(out byte[] msg, Fipc.Forever)
               == FipcResult.Ok)
            conn.Send(msg, Fipc.Forever);   // echo
        // Disconnected: the client closed or exited
    }
}
EchoClient/Program.cs
using System.Text;
using FastIpc;

if (FipcConnection.Connect("demo", out var conn, 5000)
    != FipcResult.Ok)
    return;

using (conn)
{
    conn!.Send("hello"u8, Fipc.Forever);
    if (conn.Receive(out byte[] reply, Fipc.Forever)
        == FipcResult.Ok)
        Console.WriteLine(Encoding.UTF8.GetString(reply));
}

Results, not exceptions

FipcResult

Every call returns a FipcResult: Ok, Timeout, Disconnected, Cancelled, TooLarge, Invalid, NoMemory or AddrInUse. A timeout, the peer's end and a buffer too small are normal results. Only a mistake throws, such as a call after Dispose (ObjectDisposedException).

receive into a span
Span<byte> buf = stackalloc byte[256];
switch (conn.Receive(buf, out int len, 100))
{
    case FipcResult.Ok:       Handle(buf[..len]); break;
    case FipcResult.TooLarge: break; // needs len bytes
    case FipcResult.Timeout:  break;
    case FipcResult.Disconnected: conn.Dispose(); break;
}

Zero-copy

up to conn.MaxPiece bytes

Write the message into a Span<byte> of the ring and commit it; read a ReadOnlySpan<byte> of the ring and release it. A span stays valid until its commit or release.

send in place
if (conn.SendAcquire(5, out Span<byte> buf, Fipc.Forever)
    == FipcResult.Ok)
{
    "hello"u8.CopyTo(buf);
    conn.SendCommit(5);
}
receive in place
if (conn.ReceiveAcquire(out ReadOnlySpan<byte> msg,
        Fipc.Forever) == FipcResult.Ok)
{
    Handle(msg);            // read-only, in the ring
    conn.ReceiveRelease();  // frees its room
}

RPC

FipcRpcHeader: Id, Kind, Opcode, Status, Length

Requests carry your opcode; responses echo the request's id and add a status. RpcReceive fills a span or returns a new array of any size. Use a connection for RPC or for plain messages, not both.

client: call
const uint Upper = 1;

client.RpcSubmit(Upper, "ping"u8, out ulong id, Fipc.Forever);

if (client.RpcReceive(out FipcRpcHeader reply,
        out byte[] payload, Fipc.Forever) == FipcResult.Ok
    && reply.Kind == FipcRpcKind.Response && reply.Id == id)
    Console.WriteLine($"{reply.Status}: "
        + Encoding.UTF8.GetString(payload));
server: answer
while (server.RpcReceive(out FipcRpcHeader req,
       out byte[] payload, Fipc.Forever) == FipcResult.Ok)
{
    if (req.Kind != FipcRpcKind.Request) continue;
    byte[] upper = Encoding.UTF8.GetBytes(
        Encoding.UTF8.GetString(payload).ToUpperInvariant());
    server.RpcRespond(req.Id, req.Opcode, 0, upper,
        Fipc.Forever);
}

Threads and Dispose

SafeHandle
  • On a connection, one thread at a time sends and one receives; the two may run at once. Cancel and Dispose may be called from any thread, at any time.
  • Dispose cancels the handle, so a waiting call returns Cancelled, and the native close runs once the calls in progress have returned. No call ever runs on a closed connection, and a zero-copy span stays valid until its commit or release.
  • To stop an IO thread: Dispose, then join the thread with a timeout.
  • A Disconnected connection is final: dispose it, then accept or connect a new one.

The raw layer

static class Fipc

Fipc declares the C API one to one, over IntPtr handles, pointers or spans. It costs nothing beyond the native call. Each object-layer call holds its SafeHandle, which costs about 15 ns a call, or about 30 ns per message sent and received (measured).

It enforces nothing either: Close needs the handle to itself (cancel, join the threads that use it, then close), and closing under a running call frees memory the call still uses.

raw calls
Fipc.Connect("demo", out IntPtr conn, 5000);
Fipc.Send(conn, "hello"u8, Fipc.Forever);
Fipc.Close(conn);
