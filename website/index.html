fastipc

Messages and RPC between two processes on one machine, through shared memory.

A small library written in Zig, fastipc.dll / libfastipc.so / libfastipc.dylib. Each connection is a pair of lock-free rings in memory both processes map, and a local socket that tells each side the moment the other one is gone. Use it from C, C++, Zig, Python, C#, Java, Rust, Lua, JavaScript or Go, with any of them on the other end.

Small on purpose

from docs/design/architecture.md

A minimal core that still does everything: messages of any size, zero-copy, RPC and the peer's end, without making you handle the hard cases yourself.

3,398 lines of Zig

The whole library, small enough to read

Everything behind fipc.h, every platform included, is 3,398 lines of Zig code, not counting blank lines, comments and tests.

fipc_connect · fipc_accept

Either order, any restart

Start the server or the client first: fipc_connect waits, within its timeout, for a server to listen and accept. Restart either side at any time: the other side receives every message the old process completed, then gets FIPC_DISCONNECTED, and its next fipc_accept or fipc_connect pairs it with the new one. A game loop can poll: fipc_accept with timeout 0 lets a client in within two calls.

fipc_result_t

A specific error for every failure

Every call returns one of eight result codes, named for what happened: FIPC_DISCONNECTED, the peer went away; FIPC_TIMEOUT, the call timed out and changed nothing; FIPC_TOO_LARGE, the message doesn't fit your buffer, so it stays queued and its length is reported; FIPC_ADDR_IN_USE, another server has the name. All eight.

one copy · one swap

Free on the hot path

A message is one copy into shared memory, a store and an atomic swap; the system call that wakes the other side happens only when it has gone to sleep. The peer's end never touches the rings, and a call that doesn't wait reads no clock. Copied 16-byte messages run at 49.1 million per second between two processes (Windows; all measurements).

Any language on the other end

one protocol · 100 pairs, tested

One library speaks one protocol, and every binding calls that library, so a process written in any of the ten languages talks to a process written in any other. The two processes agree on a name and on what their messages mean; the library carries the bytes.

Each language's server and client in the quick start make the same exchange, an RPC request with the payload ping, answered with PING. The repository's interop test, python devtool.py test interop, runs every language's server against every language's client, each in a process of its own, on Linux, Windows and macOS.

What it gives you

from include/fipc.h
SPSC rings

Two rings in shared memory

Every connection gets a segment of its own with one single-producer, single-consumer ring per direction. Messages never leave shared memory. The writer's and the reader's indices sit on cache lines of their own, and a publish touches one line.

futex · event

Spin, then sleep

A waiting side spins briefly, then sleeps on a futex (Linux), an os_sync address wait (macOS) or a named event (Windows). A publish costs one store and one locked swap, and the sleep protocol never loses a wake-up.

acquire · commit · release

Zero-copy, or any size

Write a message straight into the ring and read it in place, 16-byte aligned. The copying calls take messages of any size: longer than the ring, they travel in pieces and arrive whole. Nothing is allocated per message.

FIPC_DISCONNECTED

Knows when the peer is gone

A local control connection per connection (an abstract AF_UNIX socket, a named pipe) reports the peer's end as soon as its process exits or closes. No heartbeat, no timeouts, nothing left behind after a crash.

fipc_rpc_*

A thin RPC layer

Requests and responses with ids, an opcode and a status, as a 32-byte header in front of a plain message. Either side may submit and respond, with payloads of any size.

protocol v1

A specified protocol

Names, control frames, the segment header, ring frames and wake-ups are written down, so two builds interoperate bit for bit. Everything the peer writes is checked: corrupt ring content returns FIPC_INVALID, never a crash.

18 functions

Small enough to read

One header of 18 functions in front of a library you can read end to end (how small). The tests are about twice its size.

tests · TSan · chaos · fuzz

Tested to break

Unit tests, a C-API conformance suite run in one process and across processes (peers killed at every step of the handshake included), ThreadSanitizer runs, and chaos, soak and fuzz harnesses.

How it works

from docs/protocol.md

A server listens on a name and accepts one client at a time; a client connects to the name. Only processes of the same user can connect.

  1. Set up

    The server's fipc_accept accepts the client, creates a zeroed segment and offers it in a SEGMENT frame. The client's fipc_connect checks the frame and the segment's header, maps it and answers READY. Both run on the calling threads, so a client and its server run on different threads or processes. fipc_connect can return before the server's fipc_accept does; messages sent meanwhile wait in the ring.

  2. Talk

    Messages go through the rings and never touch the control connection. A frame is a 16-byte header and a piece, and never wraps, so every piece is contiguous and the zero-copy calls can hand out pointers into the ring.

  3. End

    When a process closes the connection or exits for any reason, the kernel closes its end of the control connection. The other side reads EOF: its sends return FIPC_DISCONNECTED at once, and its receives do so after delivering every message the peer completed.

Quick start

one exchange, every language

Each language has a server file and a client file: run the server in one process, then the client in another. Every pair makes the same exchange, an RPC request with opcode 1 and the payload ping, which the server answers in upper case, so any language's client works with any language's server (every pair is tested).

Installzig fetch --save git+https://github.com/fastipc/fastipc
server.zig
const std = @import("std");
const fastipc = @import("fastipc");

pub fn main(init: std.process.Init) !void {
    // rings of 1 MiB each way
    const listener = try fastipc.Listener.listen(
        init.io,
        init.gpa,
        "my_channel",
        1 << 20,
    );
    defer listener.close();
    // waits for a client
    const conn = try listener.accept(.none);
    defer conn.close();

    var buf: [256]u8 = undefined;
    // .none: no timeout
    const req = try conn.rpcRecv(&buf, .none);
    const reply = std.ascii.upperString(&buf, req.payload);
    try conn.rpcRespond(req.id, req.opcode, 0, reply, .none);
}
client.zig
const std = @import("std");
const fastipc = @import("fastipc");

pub fn main(init: std.process.Init) !void {
    const five_s: std.Io.Timeout = .{ .duration = .{
        .raw = .fromSeconds(5),
        .clock = .awake,
    } };
    const conn = try fastipc.Conn.connect(
        init.io,
        init.gpa,
        "my_channel",
        five_s,
    );
    defer conn.close();
    _ = try conn.rpcSubmit(1, "ping", .none); // opcode 1
    var buf: [256]u8 = undefined;
    const response = try conn.rpcRecv(&buf, .none);
    std.debug.print("{s}\n", .{response.payload}); // PING
}

server.c
#include <ctype.h>
#include <fipc.h>

int main(void)
{
    fipc_listener_t* listener;
    if (fipc_listen("my_channel", 1 << 20, &listener) != FIPC_OK) /* rings of 1 MiB each way */
        return 1;
    fipc_conn_t* conn;
    if (fipc_accept(listener, &conn, FIPC_FOREVER) == FIPC_OK) /* waits for a client */
    {
        char buf[256];
        fipc_rpc_msg_t request;
        if (fipc_rpc_recv(conn, buf, sizeof buf, &request, FIPC_FOREVER) == FIPC_OK)
        {
            for (size_t i = 0; i < request.len; i++)
                buf[i] = (char) toupper((unsigned char) buf[i]);
            fipc_rpc_respond(conn, request.id, request.opcode, 0, buf, request.len, FIPC_FOREVER);
        }
        fipc_close(conn);
    }
    fipc_listener_close(listener);
    return 0;
}
client.c
#include <fipc.h>
#include <stdio.h>

int main(void)
{
    fipc_conn_t* conn;
    fipc_result_t result = fipc_connect("my_channel", &conn, 5000);
    if (result != FIPC_OK)
    {
        fprintf(stderr, "connect: %s\n", fipc_result_str(result));
        return 1;
    }
    uint64_t id;
    char buf[256];
    fipc_rpc_msg_t response;
    if (fipc_rpc_submit(conn, 1, "ping", 4, &id, FIPC_FOREVER) == FIPC_OK /* opcode 1 */
        && fipc_rpc_recv(conn, buf, sizeof buf, &response, FIPC_FOREVER) == FIPC_OK)
        printf("%.*s\n", (int) response.len, buf); /* PING */
    fipc_close(conn);
    return 0;
}

server.cpp
#include <cctype>
#include <string>

#include <fipc.hpp>

int main()
{
    auto listener = fipc::listener::listen("my_channel", 1 << 20);  // rings of 1 MiB each way
    if (!listener)
        return 1;
    auto conn = listener->accept();  // waits for a client
    if (!conn)
        return 1;
    std::string payload;
    auto request = conn->rpc_receive(payload);
    if (!request)
        return 1;
    for (char& c : payload)
        c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
    return conn->rpc_respond(request->id, request->opcode, 0, payload) ? 0 : 1;
}

#include <string>

    {

        return 1;

}

Server/Program.cs
using System.Text;
using FastIpc;

// rings of 1 MiB each way
FipcListener.Listen("my_channel", 1 << 20,
    out FipcListener? listener);
using (listener)
{
    // waits for a client
    listener!.Accept(out FipcConnection? conn, Fipc.Forever);
    using (conn)
    {
        if (conn!.RpcReceive(out FipcRpcHeader request,
                out byte[] payload, Fipc.Forever)
            == FipcResult.Ok)
        {
            string upper = Encoding.UTF8.GetString(payload)
                .ToUpperInvariant();
            conn.RpcRespond(request.Id, request.Opcode, 0,
                Encoding.UTF8.GetBytes(upper), Fipc.Forever);
        }
    }
}

Server.java
import io.github.fastipc.Connection;
import io.github.fastipc.Listener;
import io.github.fastipc.RpcMessage;

public class Server {
    public static void main(String[] args) {
        // rings of 1 MiB each way; accept() waits for a client
        try (Listener listener =
                 Listener.listen("my_channel", 1 << 20);
             Connection conn = listener.accept()) {
            RpcMessage request = conn.rpcReceive();
            String text = new String(request.payload());
            conn.rpcRespond(request.id(), request.opcode(), 0,
                            text.toUpperCase().getBytes());
        }
    }
}

server.go
package main

import (
	"bytes"
	"log"

	"github.com/fastipc/fastipc/bindings/go/fipc"
)

func main() {
	listener, err := fipc.Listen("my_channel", 1<<20) // rings of 1 MiB each way
	if err != nil {
		log.Fatal(err)
	}
	defer listener.Close()
	conn, err := listener.Accept(fipc.Forever) // waits for a client
	if err != nil {
		log.Fatal(err)
	}
	defer conn.Close()
	request, err := conn.RPCReceive(fipc.Forever)
	if err != nil {
		log.Fatal(err)
	}
	err = conn.RPCRespond(request.ID, request.Opcode, 0, bytes.ToUpper(request.Payload), fipc.Forever)
	if err != nil {
		log.Fatal(err)
	}
}
